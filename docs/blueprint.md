# **App Name**: DC Converter Tester V0

## Core Features:

- Command Input: Text box for entering commands to be sent via the serial port.
- COM3 Activation: Button to activate and connect to the COM3 serial port for communication.
- Response Display: Display the response received from the COM3 serial port.

## Style Guidelines:

- Primary color: Light gray (#f0f0f0) for the background to provide a clean interface.
- Secondary color: Dark gray (#333) for text to ensure readability.
- Accent: Blue (#007BFF) for the activation button to draw attention.
- Simple, single-column layout for ease of use.
- Use clear and simple icons for the button to indicate the action (e.g., a plug icon for activation).
